# TvSettingsPlus 2.33 — исправления по документации владельца

Изучены 35 Markdown-документов Flixtone-D11-Platform в коммите `48f8cf3ab975f3f4293e2b5e571c67bd2a4355e9`. Проверка относится к существующему MainSettings и девяти разделам рабочей 2.28. Основания по функциям и оставшиеся исследования приведены в [отчёте открытых вопросов](8054_OPEN_QUESTIONS_233.md).

| Изменение | Проверка |
|---|---|
| Возвращена рабочая кнопка общего сброса из 2.28 и её штатный KeystoneUtil вызов. Подтверждение перечисляет сбрасываемые углы и два режима автокоррекции. Сообщение полного успеха требует native вызов и все 18 сохранённых значений. | JVM проверяет каждый отказ координаты, зеркала и флага, native failure и полный успех. AndroidX проверяет наличие кнопки и подтверждение. |
| Возвращены переключатели ARC, Game Mode, ALLM, AISR, Live Tone и список EDID, ранее заменённые просмотром в кандидатах. Проверяются обе зеркальные записи. У EDID проверяются диапазон, устаревшее состояние и сохранение. | AndroidX вызывает настоящие production listeners в обоих направлениях, проверяет provider значения и UI. Это подтверждает программный маршрут, аппаратный эффект для спорных пунктов описан отдельно. |
| Bluetooth OFF доступен после предупреждения и явного подтверждения наличия проверенного независимого управления. Перед выключением повторно читаются адаптер, состояние и разрешение. Есть промежуточное состояние и тайм-аут. | AndroidX проверяет диалог, обязательное подтверждение и отмену. |
| Android TV открывает назначенный проверенный HOME через существующий resolver. Неоднозначный или отсутствующий handler даёт сообщение об ошибке. | AndroidX проверяет доступный launcher и отсутствие неявного fallback при отсутствии обработчика. |
| Автопереключение HDMI использует default `0` из точного OEM `SourceSubMenuController.initData`. Пустое свойство больше не скрывает существующий контрол. | AndroidX проверяет чтение пустого, заданного и некорректного значения через production адаптер. |
| Аккаунты перечитываются при возврате. Существующие строки сохраняются, удалённые убираются, ошибка чтения отображается отдельно. Информационные строки не перехватывают фокус как кнопки. | AndroidX проверяет появление нового аккаунта и сохранение прежней строки. |
| Сохранены предыдущие исправления EQ, boot source и подтверждения видеоползунков после закрытия окна. Есть обычный переход к задержкам звука. CEC использует штатный MediaTek InputsFragment с service setters и OEM зависимостями. | Существующие AndroidX тесты EQ, меню, boot source, CEC и видеоползунков входят в общий пакет кандидата. |

Сборка создаёт отдельный `versionCode 233`. Статус после успешных проверок — `BUILT_UNTESTED`. Аппаратные положительные результаты 2.28 сохраняют свою область применимости. APK 2.33 требует отдельного испытания владельцем. Откат исходников — revert коммита доработки, предыдущие APK сохраняются в своих артефактах. Восстановление геометрии после явного сброса выполняется вручную, автоматического воспроизведения снимков геометрии нет.
