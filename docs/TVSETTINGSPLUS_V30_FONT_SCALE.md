# TvSettingsPlus MOD v30 — нативный размер текста

**Статус:** программный этап переноса с заводской базы RUIOS 8052; не адаптация 8054.

## Реализовано

- В Android TV добавлено `Интерфейс · Проектор → Размер текста`.
- Четыре **точно заводские** величины: 85%, 100%, 115%, 130%.
- `FontSizeSettingsSecondaryController` использует `Settings.System.putFloat(..., "font_scale", value)`.
- Мод использует тот же `Settings.System`, без вызова собственных сервисов или замены классов OEM. После записи перечитывает значение; не принимает 90%, 125%, Infinity, NaN.
- При нестандартном уже сохранённом размере шрифтов пункт скрыт; заводской General screen остаётся доступен.
- Native power-after-AC (v27), sound-effects (v28), app-on-boot selector (v29) сохранены.

## Результаты исследований заставки

В `ScreensaverSecondaryController` выявлены заводские ресурсы:
`rj_sleep_timeout_values = [300000, 900000, 1800000, 3600000, 7200000, 2147483647]` (5/15/30/60/120 минут/никогда),
`rj_screen_off_timeout_values = [1800000, 3600000, 10800000, 21600000, 43200000, -1]` (30/60/180/360/720 минут/никогда).

**Важный обнаруженный конфликт:** `getDreamTimeOut()` читает `sleep_timeout` через `SettingsUtil.getSystemValueInt`, но `setDreamTimeOut()` пишет через `Settings.Secure.putInt`. Пока семантика чтения `SettingsUtil` и системной службы не проверены, менять этот таймер из нового интерфейса небезопасно. OEM экран заставки сохранён. Не заявляем фиктивный перенос.

## Программные проверки

- `OemFontScalePolicyTest`: четыре значения, запись с readback, отказ, NaN, неверный тип и неподдерживаемая шкала.
- GitHub Actions компилирует JVM тесты, Java/Android 13, D8 и оригинальный APK, проверяет сертификат и сохранность OEM ресурсов.
- KuSettings и KuSourceRJ не отключаются. Альфа для 8054 **не формируется** до завершения и программной проверки переносов.
