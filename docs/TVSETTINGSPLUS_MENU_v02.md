## Правила интерфейса
- Правый столбец (обычные настройки): все меню, переключатели, ползунки, эквалайзер, режимы MEMC/HDR, источники, информация об устройстве, OTA (до начала обновления).
- В полноэкранный специализированный режим выводить только ручную коррекцию 4 углов, при необходимости ручной фокус/геометрию и штатные системные подтверждения.
- Полноэкранные OEM-диалоги с тестовой картинкой для контраста/цвета не использовать.
- Прозрачность правой панели поверх входа HDMI или видеопроигрывателя нельзя гарантировать простой заменой Activity; требует OEM/TV overlay.

## Доставка только APK (не прошивка)
- `adb install -r` поверх встроенного `com.android.tv.settings`, без изменения разделов, возможен при совпадении имени пакета, подписи и совместимом versionCode.
- AVB к установке APK через PackageManager не относится; AVB важен для модификации системных образов.
- Совпадение сертификата недостаточно, нужен закрытый ключ: если это действительно один из стандартных опубликованных AOSP test-keys, можно проверять точное совпадение соответствующего keypair.
- Выяснить sharedUserId / privileged grants и проверить системную роль до установки.
- Оригинальный TvSettingsPlus из 8052 уже повторно извлечён и сохранён в `vendor/reference/8052/APK/TvSettingsPlus.apk`. Модифицированная сборка ещё не произведена.
- Для AAPT2 остаётся задача связать vendor framework resources из родного framework-res.apk.

## Нельзя отключать без проверки
`KuSettings`, `KuSourceRJ`, `RuiAutoFocus`, `KeystoneCorrection`, `KuSetupWizard`, `TRDSERVICE`, `TrdSystemService`, `RuiYunOta`.

## Исключения
Скриншоты не включать. Режим Bluetooth-колонки не включать. Неподтверждённые функции MEMC/HDR/Game Mode/EQ не выдавать за рабочие.
