# TvSettingsPlus MOD — полное дерево и аудит готовности (8052/8054)

**Ревизия 2026-10-23.** Важно различать исходный `TvSettingsPlus.apk` и нашу v2. В подписанной v2 **не изменены DEX/UI/ресурсы**, изменён только бинарный AndroidManifest.xml: `versionCode 1→2` и обработчики старых действий `KuSettings`. Пункты со статусом **[P]** нельзя представлять как уже работающие. Это единое целевое дерево, не текущий скриншот.

## Обозначения

- **[A]** Уже имеется в AOSP/MTK-разделах и XML оригинального TvSettingsPlus 8052; появление зависит от варианта интерфейса и политики устройства.
- **[O]** Имеется оригинальный OEM-класс/контроллер в TvSettingsPlus/KuSourceRJ, но фактическая интеграция в новое объединённое меню пока не завершена.
- **[I]** Реализовано как совместимость по Intent в экспериментальной v2; это маршрут, а не новая функция/экран.
- **[P]** Запланировано к разработке, в текущем APK отсутствует в согласованном виде.
- **[H]** Только при доказанной поддержке на соответствующем железе и доступном HAL/SDK; нельзя отображать нерабочий переключатель.
- **[X]** По решению проекта **не переносить**.

**Оговорки к текущей реализации:** В исходном APK есть 151 XML-файл с 976 Preference-узлами, включая альтернативные варианты *vendor/x/compat*; они не образуют 976 одновременно доступных кнопок. Кроме того, наличие целевого Activity для Intent не гарантирует правильную семантику (например, auto-Bluetooth и выбор региональной локали).

## В. Проверка полного отказа от KuSettings

| Старый компонент / функция | Эквивалент | Статус |
|---|---|---|
| SettingActivity, android.settings.SETTINGS | MainSettings, legacy alias | [I]; требует теста intent resolution и кнопки пульта |
| MyWifiActivity | NetworkActivity и штатный Wi-Fi | [A][I] |
| MyBluetoothActivity | AddAccessoryActivity (временный маршрут к сопряжению); полный список устройств находится в AccessoriesFragment | [A][I], не полная parity |
| MyAutoBluetoothActivity | AddAccessoryActivity через AUTO_BLUETOOTH | [I] маршрут; поведение автоподключения НЕ доказано эквивалентным |
| LanguageActivity | LanguageActivity | [A][I] |
| LanguageLocalActivity | LanguageActivity | [I], отдельный региональный экран пока не воспроизведён |
| DateTimeActivity / MyZonePicker | DateTimeActivity / TimeZoneFragment | [A][I] |
| ProjectionActivity | TvSettingsPlus.uicustom.MainActivity | [I], точный переход в «Проекция» ещё требуется |
| AllAppActivity | AllAppsActivity | [A][I] |
| ScreenshotActivity / ScreenServices | Нет | [X] согласованное исключение |
| BootupReceiver + MySetTimeService | Сохраняем KuSourceRJ BootupReceiver/TimeService | Не переносим целиком; требуется тест восстановления TimeService после сбоя |
| KuSetupWizard | Оставить самостоятельным пакетом | Исследование собственных классов/манифеста; аппаратный тест первого запуска |
| Системный services.jar / WhaleTV / xtzm_setting | Не заменяются APK-манифестом | Остаточные зависимости, требуется трассировка и/или отдельные совместимые маршруты |
| Пять полос EQ, MEMC, HDR, игра, термопанель | Целевые пункты выше | [P][H] не включены в v2 |

**Важное ограничение**: нельзя доказать отсутствие абсолютно всех runtime-зависимостей одной статикой: возможны reflection, Binder, настройки провайдера, SYSTEM_UID, OEM CEC/remote, чтение XML по runtime, аварийное восстановление. Полное отключение KuSettings запрещено до испытаний на устройстве.
