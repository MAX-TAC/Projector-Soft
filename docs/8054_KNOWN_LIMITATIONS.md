# Подтверждённые ограничения v39

- **Нижние редакторы PQ.** Штатный `ProgressBarVerticalFragment.onPreferenceChange` обслуживает пять OEM-регулировок. Вызов полного `PictureFragment.onCreatePreferences` включает `disableAutoBackLight`. Изолированный редактор пока не подключён: `MtkTvConfigBase` использует `inputGroup=-1`, а обратная синхронизация TvServices асинхронна. Для записи требуется стабильное подтверждение адресата по HDMI, SDR/HDR и режиму, readback и ручной возврат. [Трасса PQ](../research/8054/PICTURE_BLOCK_STATUS_8054.md)
- **Гамма.** `GammaFragment.onCreatePreferences` использует панели OEM из `getArrayIdsByCustomer("picture_gamma")`, а `onPfTreeClick` пишет `picture_gamma`. TvServices связывает ключ с `g_disp__disp_gamma`. Это пользовательский дискретный редактор, отделённый от калибровки Dolby Vision. Видимость для конкретного профиля, значения и обратное чтение надо подтвердить до включения записи. [Трасса](https://github.com/MAX-TAC/Projector-Soft/actions/runs/44721991789)
- **HDR, MEMC и RGB.** `picture_list_hdr` сопоставлен с `g_video__vid_hdr`; семантика реальных HDR-сигналов и восстановление остаются открыты. `ColorTemperatureFragment` использует `picture_red_gain`, `picture_green_gain`, `picture_blue_gain` с `g_video__clr_gain_r/g/b`; read-only строки вынесены в свой экран. `MJCFragment` содержит пользовательский эффект. MEMC demo исключён. Запись всех этих настроек требует подтверждения контекста PQ. Для динамического контраста ещё не установлен точный пользовательский callback и допустимый набор значений.
- **Тембр.** Bass/Treble имеют `g_audio__aud_bass` и `g_audio__aud_treble` и входят в одну карту `initSoundStyleMap` с EQ. Отдельное действие в DSP по статике пока не доказано, поэтому они скрыты в основном дереве. PEQ13 остаётся заводским маршрутом.
- **Системные функции.** Bluetooth ON/OFF, отдельный countdown, reset, OTA, отдельный экран сна/энергосбережения и домашнего экрана ждут проверки штатных контрактов. Пункт состояния сна только читает параметры. Компонент Reset сохранён. TimeService, нагрев/охлаждение, HID AutoPair и KuSettings остаются у исходных владельцев.
- **Кнопки пульта.** Local Settings открывает MainSettings, Local Source открывает Sources. Владелец глобального входа на HOME/HDMI динамически не подтверждён. Без отдельного разрешения изменения сторонних APK, framework и маппинга клавиш не входят в этот кандидат.
