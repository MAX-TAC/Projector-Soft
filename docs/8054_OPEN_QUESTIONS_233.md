# Открытые вопросы для TvSettingsPlus 2.33

Основание — документация Flixtone-D11-Platform в коммите `48f8cf3ab975f3f4293e2b5e571c67bd2a4355e9`, рабочий APK владельца 2.28 (`e0e75ee`) и сохранённая диагностика 27 ноября 2026 года. Вопросы ниже сохраняют пользовательские контролы из 2.28. Изменение их доступности требует отдельного решения владельца.

| Функция | Данные и спорный момент | Что исследовать дальше |
|---|---|---|
| EDID | Документ предлагает четыре значения. Штатный контроллер ограничивает каталог по getter MediaTek, общий Global не содержит номера HW6/HW7. | Для одного внешнего источника прочитать реально выданный EDID отдельно на каждом порту и проверить восстановление соединения. В 2.33 сохранён список 2.28, исправлены диапазон ввода, stale write и ложный Auto при отсутствующем значении. |
| ARC/eARC | В документации есть утверждение об отсутствии eARC, но в штатном APK есть `isSupportEARC`, `sound_earc` и `setEarcEnable`. Сохранённый ARC-флаг не доказывает установленный канал звука. | Проверить штатный контракт и handshake с совместимым ресивером. Переключатель ARC сохранён. Выключение CEC штатным callback может менять eARC и auto-off, поэтому их исходные значения следует проверить отдельно при испытании CEC. |
| Игровой режим | Ключи принимаются. Владелец ранее отмечал эффект, измерения MEMC/задержки/геометрии на exact 2.28 в комплекте отсутствуют. OEM источник при включении Game может вызвать resetTrapezoid. | Установить реальные побочные действия пользовательского Global маршрута и сравнить два состояния на одном видеоисточнике. Сохранены обе записи исходного переключателя, добавлено подтверждение обоих значений. |
| ALLM | Документ функции называет механизм рабочим, аппаратный отчёт сообщает, что запрос не изменился. `mAllmSupported` описывает возможность, а `mAllmRequested` в display не обязательно отражает настройку HDMI-приёмника. | Найти обработчик `AdvanceVideoALLMPref` и проверить запрос от совместимого HDMI-источника. Контрол сохранён. |
| AISR и Live Tone | В аппаратном отчёте не видно эффекта на Android-приложениях. Маршрут видеопотока и применимость к HDMI остаются открытыми. | Сравнить одинаковый материал с нужным разрешением и динамическим диапазоном. Контролы сохранены. |
| Автокоррекция | Рабочая 2.28 допускает отсутствующие зависимые properties, а старые тесты требовали запрета. Три зависимых свойства в снимке устройства равны `0`. | Установить OEM default пустого свойства и различие ошибки чтения и отсутствия. В 2.33 восстановлена точная семантика 2.28. Тесты фиксируют совместимость, аппаратную безопасность неизвестного состояния они не доказывают. Для активных зависимостей сохранена исходная проверка 2.28. |
| Автопереключение HDMI | Пустое свойство в снимке приводило к отсутствию строки. По точному `SourceSubMenuController.initData` установлен штатный `getInt(key, 0)`, и это чтение перенесено в адаптер. | Программный default и появление строки исправлены. Реальное переключение при hotplug проверяется только с подключённым HDMI-источником. |
| EQ на HDMI/ARC и профили по выходам | Работа на динамиках и Bluetooth подтверждена владельцем. Документ расширяет вывод на любой выход и предлагает отдельные профили. | Проверить активный PCM-тракт HDMI/ARC отдельно. В 2.33 сохранена общая кривая и добавлено её применение при открытии нового процесса из предыдущих исправлений. Отдельные профили и passthrough требуют собственного контракта. |
| Снятые OEM Activity | В 2.28 отсутствовали адресаты трёх реальных вызовов. Часть остальных объявлений — внешние системные входы и alias. | Для очистки сначала перенести каждый используемый вызов и проверить внешних клиентов. Кандидат сохраняет штатные декларации, обычное меню остаётся единым. |

`ADR-0003` описывает прошивку разделов и предписывает длительное восстановительное исследование. Текущее задание владельца разрешает разработку APK и проверки CI. Операции с разделами, установка и аппаратные переключения в эту доработку не входят. `MOD-V43-SPEC` указывает базу 8052 и платформенную подпись, а действующий Exact workflow использует точный APK 8054 и сверяет сертификат. Применяется действующий точный маршрут сборки.
