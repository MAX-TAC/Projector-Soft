# TvSettingsPlus MOD — porting native AC-power boot (v27)
Status: software-tested experimental build for the 8052 factory base. No 8054-specific adaptation.

## Реальная функциональность

В разделе `Питание · Проектор` добавлен переключатель **«Включать после подачи питания»**.
Он использует оригинальные публичные методы заводского `MtkUtil.getInstance()`:
`isElectricityBoot()` для чтения и `putElectricityBoot(boolean)` для записи.
Их наличие и сигнатуры подтверждены в статическом аудите оригинального TvSettingsPlus.

- Никаких собственных GPIO, PMIC, sysfs, system properties или обхода OEM.
- При отсутствии заводского класса, метода или корректного возвращаемого значения
  пункт не отображается.
- При записи новое значение **обязательно перечитывается** через OEM API;
  при ошибке переключатель остаётся в исходном состоянии.
- При повторном выборе прежнего значения запись не выполняется.
- `KuSettings` и `KuSourceRJ` сохраняются, вентиляторы не затрагиваются.

## Программное тестирование

- `OemAcPowerBootPolicyTest` проверяет отсутствие OEM getter, ошибку, запись,
  повторный выбор, валидацию значения, отсутствие ложного подтверждения.
- `test-light-mode-android.yml` компилирует весь Java адаптер на Android 13 и
  запускает pure-JVM тесты.
- `build-tvsettingsplus-inline-v27.yml` компилирует OEM-aware DEX, тестирует
  backend policy, пересобирает и подписывает APK, проверяет manifest, certificate,
  OEM DEX и неизменённые ресурсы.
- **Работа физического выключателя питания и сохранение режима после перезагрузки
  не проверялись.** Успешная CI сборка не доказывает работу на 8054.

## Дальнейшие незакрытые задачи

1. Native перенос кнопочного звука/фоновой заставки после аудита оригинальных callback.
2. Автоматическое Bluetooth переподключение: подтвердить штатный сервис и намерения
   `KuSettings.MyAutoBluetoothActivity`, не вмешиваясь в BT stack вслепую.
3. Отдельно проверить зависимость `KuSettings.MySetTimeService` от
   `KuSourceRJ.TimeService`. Не отключать KuSettings до тестов на железе.
4. Только после программной проверки всех переносимых функций и итогового ревью
   разрабатывать отдельную адаптацию под RUIOS 8054.
