# TvSettingsPlus MOD — ALPHA 1 для RUIOS 8054 (v26)

**Статус:** подписанный экспериментальный APK для тестирования на реальном FlixTone D11 Master, Android 13; **аппаратных испытаний ещё нет**. Не финальный релиз. Дата подготовки: 11.11.2026.

## Архитектура / происхождение бинарника

- Целевой пакет: `com.android.tv.settings`, повышение `versionCode` до **26**. Это обновление системного TvSettingsPlus, не полная прошивка.
- APK собран из `vendor/reference/8052/APK/TvSettingsPlus.apk`, SHA-256 `e4184a13fbf56fa069effc6a40ea50c0da7e9190321b389f59ba34700a80d0a1`. Исследования ранее подтвердили **тот же SHA** оригинального TvSettingsPlus в архивном образе **RUIOS.8054.1.0.1**. Однако установленный у владельца 8054 **может отличаться**.
- Подпись подписанного APK в CI сверяется с оригинальным platform certificate и проверяется `apksigner`; остальные OEM DEX/ресурсы не переписываются, кроме проверенных частей brightness/navigation.
- Ни OTA, ни boot/vbmeta, ни AVB и bootloader не меняются.
- Сохранены OEM KuSettings, KuSourceRJ, SetupWizard, RuiAutoFocus, KeystoneCorrection, RuiYunOta, аппаратная защита от перегрева.
- **Отдельная альфа-ревизия v26:** `Alpha8054Policy` запрещает показывать прямые новые аппаратные контролы, если не подтверждены Android 13, машина 8054 и ровно 2 порта HDMI. Если идентификаторы противоречат друг другу или данные отсутствуют — видны только сведения/диагностика MOD; штатное Android TV меню остаётся.

## Что доступно в альфе

- Обычный ярлык «Настройки» (Android TV/Leanback + стандартный launcher).
- Изображение: заводские режимы, цветовая температура, настраиваемые параметры картинки, HDR/MEMC при наличии OEM state.
- Звук: заводские режимы, басы/высокие частоты, пять полос OEM EQ 120/500/1500/5000/10000 Гц, eARC через оригинальную панель.
- Источники: только аппаратно обнаруженные HDMI, настройки EDID, HDMI hotplug, источник и приложение при включении, OEM HDMI Game/CEC fallback.
- Проекция: заводские экраны калибровки, фокусировки и трапеции; ориентация.
- «Об устройстве · Проектор»: диагностика совместимости, температура Android (при доступных датчиках), ручное обновление показаний, заводское локальное/онлайн обновление.
- KuSettings совместимые Intent aliases для основных штатных настроек Wi-Fi/Bluetooth/язык/дата и время/список приложений.
- Нативные предпочтения интегрированы в Android TV MainFragment; часть OEM-страниц **пока открывается как отдельная Activity**. Это не полная замена всех OEM контроллеров.

## Установка на тестовый 8054

1. Сделать снимки действующей версии прошивки, убедиться, что есть доступ по ADB и компьютер с установленным Android `platform-tools`.
2. Скачать ZIP артефакта из GitHub Actions: **tvsettingsplus-8054-alpha1-experimental**. Распаковать файлы в одну папку.
3. Подключить один проектор и авторизовать ADB. Запустить `install-8054-alpha.cmd` на Windows из этой папки.
4. Скрипт **до установки** проверит `ro.rjpj.machine.id=8054`, Android 13, оригинальное местоположение `com.android.tv.settings`, SHA-256 установленного APK и сохранит резервную копию `TvSettingsPlus-original-8054.apk`. На отличающемся APK/неизвестной ревизии **остановится**.
5. После ручного подтверждения `YES` выполняется `adb install -r`. Старый KuSettings **не отключать**.
6. Если скрипт заблокировал установку, **не обходить проверку вручную**: сначала прислать значение `getprop ro.rjpj.machine.id`, версию Android, SHA APK и установленную версию RUIOS.

## Проверки после установки

1. Открыть ярлык «Настройки»: нет вылета и пустых экранов, работают пульт и «Назад».
2. Открыть «Об устройстве · Проектор» → «Альфа 8054 — совместимость». При двух HDMI и Android 13 должен быть статус *разрешены экспериментальные пункты*, но это не доказывает, что они работают.
3. В «Диагностика совместимости MOD» нажать «Копировать»; сохранить текст отчёта. Не включать никакие опасные опции.
4. В «Источники» проверить наличие **двух** реальных HDMI (нет третьего/четвёртого); переключение на тестовом экране, EDID/CEC только с понятным откатом.
5. Проверить подключение Bluetooth-пульта, Wi-Fi, звук, обычное HDMI воспроизведение.
6. Фокус/трапецию сначала проверить в заводском режиме (не выполнять автоматические изменения без возможности возврата), сравнить с заводским состоянием.
7. Открыть заводскую панель обновления ПО, **не запускать OTA** в первом тесте.
8. Проверить, что температура недоступных датчиков не выдаётся за реальную; контроль охлаждения KuSourceRJ не отключён.
9. Перезагрузить устройство и повторно проверить штатный запуск, HDMI/звук, восстановление от выключения. **KuSettings остаётся включённым**.

## Откат при сбое

- Если Android TV Settings открывается: использовать штатный пункт приложения «Удалить обновления» для `com.android.tv.settings`, если такой пункт существует.
- Если APK установлен поверх системного пакета и его оригинал действительно присутствует в `/system_ext/priv-app`, на компьютере с ADB **после проверки `pm path com.android.tv.settings`** допустима команда `adb uninstall com.android.tv.settings` для удаления установленного пользовательского обновления и возврата к заводской системной версии. Это может сбросить данные настроек.
- **Не использовать** `adb shell pm disable-user`, `pm uninstall --user 0` и не удалять APK из `/system`. Если пакет уже не существует в исходной системной секции или у устройства другая прошивка — откат требует отдельной проверки.

## Не перенесено или не проверено — известные блокеры финала

- `KuSettings.MyAutoBluetoothActivity`: штатное AOSP сопряжение есть; полная OEM логика автоматического переподключения требует тестов.
- `KuSettings.MySetTimeService` контролирует `KuSourceRJ.TimeService`, важную для охлаждения. Резервный монитор MOD не доказан аппаратно эквивалентным. **KuSettings не отключать.**
- `settingApps` в системе всё ещё указывает на `com.my.settings`; поведение кнопки настроек из OEM лаунчера нужно проверить.
- Сторонние OEM firmware и настройки восстановления обновляются отдельно; 8054 ToF/motor controllers остаются заводскими.
- Dual BT Audio, полноценный единый экран вместо всех оригинальных OEM Activity, точная температура системных вентиляторов без OEM API остаются исследовательскими задачами.

**Итог:** Альфа 1 — это сборка для контролируемых испытаний на 8054, а не доказанный перенос каждой функции KuSettings и не разрешение на его отключение.
