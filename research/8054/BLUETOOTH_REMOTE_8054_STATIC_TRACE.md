## TvSettingsPlus BluetoothReconnectService

[Инвентаризация методов, run 44116773583](https://github.com/MAX-TAC/Projector-Soft/actions/runs/44116773583) и [точный smali trace, run 44117754570](https://github.com/MAX-TAC/Projector-Soft/actions/runs/44117754570) относятся к оригинальному TvSettingsPlus.apk 8054. `BluetoothReconnectService#onCreate`, `smali_classes14/.../BluetoothReconnectService.smali:857-1025`, получает `BluetoothAdapter`; если `SystemProperties.get("atvremote.disable_bt_discoverable")` не равно `"true"`, вызывает `BluetoothAdapter#setScanMode(0x17)`. Затем регистрирует BT/profile/system receivers, запрашивает profile proxy `0xb` и `0x2`, учитывает `MtkTvUtil#QHB_IsQuietHotBoot()` и вызывает `reconnectPhone()`.

`getLastConnectedPhoneDevices`, строки 513-625, читает `SaveValue["phone_mac_address"]`, перебирает `BluetoothAdapter#getBondedDevices()` и сравнивает MAC с `BluetoothDevice#getAddress()`. `reconnectPhone`, строки 627-657, передаёт найденное устройство в `BluetoothDevicePairer#startPairing`. Аналогичный `getLastConnectedA2dpDevices`, строки 399-511, ищет `SaveValue["audio_mac_address"]`. В просмотренных методах **нет точной проверки HID major `0x500` или OEM имени Remote**; назначение службы для штатного пульта этим не доказано. Связь этой службы с AutoPair/KuSettings и её фактический эффект после cold boot неизвестны. Не отключать службу только на основании имени или этой статической выборки.

[Callback trace, run 44119451026](https://github.com/MAX-TAC/Projector-Soft/actions/runs/44119451026): `$2#onServiceConnected`, строки 38-174, получает `getLastConnectedPhoneDevices`, сохраняет `BluetoothA2dpSink` proxy и вызывает `setConnectionPolicy(device,0x64)`; `$3#onServiceConnected`, строки 38-100, сохраняет `BluetoothA2dp` proxy. Receiver `$4#onReceive` по `ACL_CONNECTED`/`ACL_DISCONNECTED` разделяет major class `0x200` для `phone_mac_address` и `0x400` для `audio_mac_address` (строки 132-195); `$5#onReceive` обновляет эти ключи по изменениям состояния профиля. `$6/$7` реагируют на SCREEN_ON/OFF и QHB.CANCELLED через Handler. `$8#handleMessage` содержит A2DP `setConnectionPolicy` после проверок BT/QHB. Это конкретная аудио/phone цепь; в этих ветвях не найден HID major `0x500`. Полный анализ всех внешних вызовов и фактических профилей устройства ещё нужен.
