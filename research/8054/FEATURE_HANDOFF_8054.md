# TvSettingsPlus MOD 8054 — пользовательская комплектация

| Раздел | В TvSettingsPlus | Штатный редактор или маршрут |
|---|---|---|
| Изображение | Нативные строки PIC01–PIC12 для чтения | Редактирование ждёт подтверждения адресации PQ-профиля и восстановления |
| Звук | Профиль, громкость Android, доступные bass/treble/surround/AVC, звуки интерфейса и пятиполосный EQ | Подтверждённый `AudioOutputActivity`, условные редакторы Dolby/DTS и штатный eARC |
| Проекция | Автофокус при включении и движении, автотрапеция при движении по отдельности | Штатное меню проектора и `KeystoneCalibrationActivity`. Положение, ручной фокус с пульта и OEM-коррекция остаются в исходных обработчиках |
| Оптическая яркость | Четыре режима KuSourceRJ с чтением сохранённого режима на подтверждённой customer-0 конфигурации | Штатное меню при недоступности условного MOD-контрола |
| Источники | Выбор HDMI 1/2 через LiveTV, статусы, Auto Device Off, автопереключение, источник и приложение при включении | Основной CEC/eARC, EDID и игровой режим используют сохранённые OEM-обработчики |
| Система | Питание при подаче сети, политика бездействия, размер текста, модель | Android Wi-Fi, язык, дата и время, приложения и Bluetooth-сопряжение; OEM hotkey Settings сохранён |

Пункты появляются при доступном для конкретной конфигурации обработчике и исходном значении там, где оно требуется. Состояния, полученные из Android или записей OEM, не подтверждают физический эффект на выходе.

- **SYS07.** «Таймер выключения» открывает штатное расписание `TimerSetActivity` без аргументов. Оно создаёт `TimerFragment` с `set_timer_power_off_timer`; Android timeout и отдельный `SwitchOffTimerService` этим маршрутом не подменяются. Маршрут проверяется точным Manifest и smali при сборке и состоянием Activity при построении меню. На устройстве проверить открытие, закрытие без изменений, редактирование с возвратом исходного расписания и срабатывание в отдельном согласованном тесте. [Трасса](https://github.com/MAX-TAC/Projector-Soft/actions/runs/44393750865/job/135118017636)
- **SND12.** Нативные ползунки SPDIF и динамиков появляются при штатных признаках доступности. [Единицы, readback и тесты](AUDIO_DELAY_8054.md)
- **PRJ06/07/10.** Отдельные нативные строки запускают подтверждённые штатные FourCorner, H/V и DigitalZoom Activity. Пункт `KeystoneCalibrationActivity` сохранён отдельно. На устройстве предстоит проверить D-pad, Back и возврат геометрии.
- На устройстве проверить доступность отдельных OEM-пунктов, Back/D-pad, кнопку Settings, HDMI 1/2 и запуск, аудиовыход и EQ, автофокус и автотрапецию, а также оптическую яркость и тепловую реакцию. Критические OEM-компоненты сохранены.

Нерешённые настройки и способы доставки перечислены в [матрице 96 функций](DELIVERY_STATUS_8054.md). Программный этап остаётся открытым. Аппаратная проверка, совместимость установленного APK и восстановление рассматриваются отдельно.

## Приоритет оставшихся функций

Срез канонической матрицы `NOT_IMPLEMENTED` (20 строк). Приоритеты ниже не меняют категорию доставки.

| ID | Область | Что проверять дальше |
|---|---|---|
| NAV13 | Служебный OEM-маршрут | Handoff описывает `KuSettings.ScreenServices` и системный сервис захвата. Пользовательский entry на 8054 не подтверждён. Не добавлять кнопку и не отключать службу. |
| PIC14 | Пользовательское, кандидат при отдельном маршруте | Искать настройку обрезки для конкретного HDMI и доступный исходный размер. `Factory.OverScanAdjustViewHolder` сам по себе подтверждает только заводской маршрут. |
| SND08 | Пользовательское, кандидат при доказанной поддержке | Найти потребительский редактор и проверить профиль/выход, единицы, диапазоны, сохранение и откат. FAC03 — отдельный заводской интерфейс. |
| PIC13 | Диагностика изображения | MEMC Demo — демонстрация. Не смешивать с доступными пользовательскими режимами MEMC. |
| PIC15 | Сервисная диагностика | Тестовые паттерны для проверки дисплея. Потребительскому меню не требуется управление заводскими паттернами. |
| PIC18 | Диагностика, потенциальный read-only | Panel Info допускает отдельную оценку read-only маршрута. Сведения о панели не являются измерением разрешения проекции. |
| FAC01 | Сервисная диагностика | Информация о чипе. Допустим отдельный проверенный read-only источник, если есть данные, которые нужны пользователю. |
| FAC02 | Сервисная диагностика | Панель/PQ, не переносить редакторы заводских коэффициентов. |
| FAC03 | Заводское аудио | PEQ/GEQ с заводским сохранением не выносить в потребительское меню. |
| FAC04 | Сервисное аудио | Заводские интерфейсы DTS/Dolby. Потребительские экраны рассматриваются отдельно по SND09/SND10. |
| DBL01 / DBL02 | Отдельный этап продукта | AirPlay/DLNA/Chromecast, Miracast. |
| DBL03 / DBL04 | Отдельный этап продукта | OEM store, лаунчер. |
| DBL06 | Сервисный/демонстрационный | Retail/demo, вне текущего меню. |
| DBL07 | Отдельный этап продукта | OTA poll, вне текущих изменений. |
| DBL08 | Отдельный этап продукта | OEM recommendations. |
| BOOT01 / BOOT02 / BOOT03 | Отдельный этап загрузки | Надпись FULL HD, загрузочная анимация и звук. |
