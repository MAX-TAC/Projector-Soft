# План разработки пользовательских настроек 8054

Цель: единый интерфейс Android TV со штатными пользовательскими функциями. Полный реверс 96 функций до закрытого HAL не является условием разработки.

`development_queue_8054.json` хранит категории всех 96 функций отдельно от прежних статусов доказательств. CRITICAL требует подробного доступного анализа побочных действий; USER_SETTING использует общий UI → Settings/API → observer → config, диапазоны и откат; STANDARD_ANDROID использует Android API/Intent с проверкой OEM исключений. BLOCKED/DEFERRED из матрицы сохраняются независимо от категории. Factory-калибровки остаются закрыты. Статус RUNTIME_TEST_REQUIRED означает отсутствие аппаратной проверки, не готовность любого конкретного контрола к переносу.

Общий анализ: `settings-8054-batch.yml` скачивает текстовый artifact существующего run 44125184745 и извлекает все доступные literal Map.put пары из полных тел TvServices init-методов. `STATIC_MAPPING` не доказывает достижимость UI, диапазоны или специальную ветку; их проверяем группами. Повторного получения firmware и декомпиляции нет. Следует сохранить JSON artifact в репозитории: старый исходный artifact имеет ограниченный срок хранения.

Порядок реализации: изображение → звук → HDMI → проекция → система. На блок один пакет проверок. Закрытый HAL не блокирует обычную настройку при подтверждённом штатном маршруте; аппаратный результат остаётся RUNTIME_TEST_REQUIRED. Автоматическое отключение OEM служб и любые операции на проекторе требуют разрешения владельца.

Текущее состояние изображения после P1 review: прямые MOD list/sliders/HDR/MEMC скрыты, доступна штатная OEM страница. UNKNOWN запрещает новые записи и snapshot; старые UNKNOWN/legacy records сохраняются без replay. BUILT_UNTESTED относится к gate/делегированию, не к готовому inline rollback. Подробности PICTURE_BLOCK_STATUS_8054.md. Следующий активный блок — звук.

Проверка: compile всех Java API33, существующие policy/regression CI, synthetic extractor test с перезаписью регистра. На оборудовании после разрешения: изменить одну настройку, восстановить, переоткрыть страницу, сверить Global и MediaTek config; повторить после перезапуска приложения и при частичном отказе записи. Исходный откат: revert коммита блока; на проекторе изменений сейчас нет.
