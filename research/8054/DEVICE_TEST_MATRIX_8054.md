# Аппаратная матрица TvSettingsPlus MOD 8054

План для FlixTone D11 Master 8054. Все сценарии имеют статус `RUNTIME_TEST_REQUIRED`. Готовность плана не даёт допуска к установке или записи. Рабочий Draft PR остаётся открыт. Контрольный APK `9f8fc64` и его комплект не заменяются новым артефактом.

## Допуск до фазы A

| Шаг | Что должно быть подтверждено | Статус |
|---|---|---|
| P0. Исходный STOCK | Отдельное разрешение владельца. Текущий working projector, источник питания и связь ADB стабильны. Существующий `preflight.py` фиксирует machine/API, package paths, versionCode, подпись, shared UID, SELinux и разрешения. | Готов план read-only, выполнение ожидает разрешения |
| P1. Совместимость и возврат | На основании реального PackageManager установить, что выбранный кандидат совместим с установленным package, что штатный APK сохранён и рабочий ADB переживёт отказ Settings. Проверить доступность удаления только обновления и фактического возврата STOCK. Версия или подпись из CI в одиночку недостаточна. | Заблокировано до P0 и оценки восстановления |
| P2. Первый запуск | Утверждённый способ восстановления и согласованный APK с SHA-256. Сохранить исходные четыре Android inactivity значения. Если они расходятся с политикой MOD, запуск будет потенциально записывающим и требует отдельного согласия. | Заблокировано до P1 |
| P3. Допуск фазы C | Для отдельной функции известны источник истины, исходное значение, разрешённый диапазон, способ ручного возврата и независимый контроль. Для строгой геометрии, питания и оптики отдельный допуск. | Заблокировано до фаз A/B и отдельного разрешения |

Сохранить контрольный отчёт вне приложения. Физический сброс и перепрошивка отсутствуют как способы отката в этой матрице. При падении Settings, потере ADB/D-pad, отказе охлаждения или невозможности подтвердить исходное состояние остановить испытание. Программа тестов не включает отключение KuSettings, KuSourceRJ, TimeService, watchdog и OEM-зависимостей.

## Фаза A — запуск, навигация и жизненный цикл

| Сценарий | Что проверяется | Условия и стоп |
|---|---|---|
| A1. Первый запуск | Stock launcher Settings и проверенный ярлык MOD. Группы Android TV, значимые подписи, отсутствие дубликатов и пустых категорий. Фокус D-pad на первом доступном пункте, Back возвращает к рабочему экрану. | Только P2. Контролировать policy inactivity. Stop при crash/black screen/потере кнопки Settings. |
| A2. Android | Wi-Fi, язык, дата/время, приложения. Открыть каждый экран и вернуться без подтверждения изменений. | Проверить целевое приложение. При отказе запуска остаётся рабочее меню. |
| A3. Bluetooth | Информация пульта и Cancel/Back диалога сопряжения. Сохранённый рабочий пульт остаётся подключён. | В фазе A не удалять pairing и не менять AutoPair. |
| A4. OEM звук / время | AudioOutput, Dolby/DTS при штатной доступности, TimerSetActivity. Назад без выбора новых опций. Повторный вход и отказ недоступного target. | Переходы, которые открывают экран с неизвестной инициализацией, сначала проверяются статически. |

| A7. Повторное открытие | Повторный вход, фон/возврат, переход между страницами, View recreate, диалоги Cancel. Единственный набор rows, восстановленный фокус и отсутствие лишних callbacks. | Сравнить после 2–3 циклов, не имитировать отказ путём отключения системного пакета. |

## Фаза B — чтение состояния

| Система | Что записать и как интерпретировать |
|---|---|
| PIC18 / FAC01 | Наличие строк после холодного старта и возврата из штатного меню, тип/версия и конфигурационные размеры в пкс. SoC из Android Build. Сохранённые поля не измеряют оптику. |
| HDMI | Идентичность HW6/HW7, наличие и сигнал каждого входа, текущий формат и EDID stored code отдельно от активного sink. Обратная проверка активного режима и link negotiation возможна только внешними данными. |
| Изображение | PIC01–12 сохранить вместе с активным входом, режимом, SDR/HDR и источником записи. При смене профиля сравнивать новый снимок. |
| Звук | Профиль, динамики/BT/HDMI ARC/eARC, 5 EQ полос, delay и отдельный Android stream volume. EQ baseline в MOD относится к текущей странице. Уровень/фактическую задержку сверять отдельно. |
| Проекция | Исходная геометрия, автофокус/движение, режим установки, Vertical/Screen/Obstacle dependencies. Без входа в пишущую инициализацию. |
| Питание и температура | Android inactivity, расписание выключения, current electricity-boot, shared boot selector. Сохранить температурные/вентиляторные данные и состояние записей вместо вывода о реальной работе из одного package flag. |

## Фаза C — раздельные изменения

Каждая строка означает отдельный допуск и один параметр. После изменения сравнить с исходным снимком этой же конфигурации, вернуть значение через проверенный штатный интерфейс и подтвердить его перечитыванием. Не переходить к следующей строке при неопределённом состоянии. Для возврата геометрии и оптики требуется исходный видимый и штатный программный снимок.

| Функция | Исходное состояние и одно допустимое изменение | Проверка, побочные действия и ручной возврат | Немедленная остановка |

| NAV08 | Сверить OEM-size, выбрать соседний штатный размер | Отрисовка после recreate, вернуть исходный размер в том же UI | Потеря доступности меню |
| NAV09 | Четыре Android inactivity значения и отдельное OEM расписание | Проверить идемпотентность только при согласованной политике. При отличии проверять policy и OEM schedule по отдельности. Возврат Android исходного допустим только с согласованным проверенным способом | Любое непредвиденное выключение, не подтверждённый возврат |
| SND01 | Исходный sound_style и выход, выбрать один OEM preset | Проверить обновление rows и звук. Вернуть исходный preset при том же выходе | Профиль/выход изменился в фоне |
| SND02 / SND03 | Зафиксировать bass либо treble; тестировать по одному шагу в каждом отдельном запуске | Readback и слышимость, вернуть значение в исходном режиме и выходе | Неподтверждённый диапазон или клиппинг |

| Доп. громкость / Dolby / DTS | По одному свойству, исходный эффект или Android stream volume | Наблюдать ограничение устройства; вернуть в том же штатном подменю | Выход сменился, эффект невозможно повторно прочитать |
