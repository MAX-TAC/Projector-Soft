# EDID 8054: Settings.Global → TvServices, статическая цепочка

Источник: оригинальные 8054 APK из backup ZIP SHA-256 `4f53f2224c98b4c832a19a591b9dd7f925bde28528b5674a09732c0f0e41d362`; [TvSettingsPlus trace, run 44106214713](https://github.com/MAX-TAC/Projector-Soft/actions/runs/44106214713) и [TvServices/MtkTvInput scan, run 44107731141](https://github.com/MAX-TAC/Projector-Soft/actions/runs/44107731141). TvSettingsPlus.apk SHA-256 `f8e0c6fe0f46e7eb8db651c31d85ef8b32a769b37e4dd0f96ed19a64725d74ee`; TvServices.apk SHA-256 `2934ca9334afd0a2af85786aa0593d27da216086c7eb9b0c9b801f412516b77d`; MtkTvInput.apk SHA-256 `59040206f84c7fbd85f61f885cb5edbdd977ebea3a2a3b20a6b7afc138df72b2`.

1. В `TvSettingsPlus` два OEM getter: `EdidSourceSecondaryController#getEdidVersion` и `SourceSubMenuController#getEdidVersion` передают `0x6` в `MtkTvAVModeBase#getVideoInfoData` и читают `getU8EdidIndex`. Восемь radio `onClick` в secondary controller и fragment пишут значения 0..3 в один `Settings.Global.tv_input_hdmi_edid_version` через `SettingsUtil#putGlobalValueInt`. В этих обработчиках физический порт не передаётся.
2. `TvServices.TVMenuSettingsService#initMapdata()V`, `smali/com/mediatek/tv/agent/TVMenuSettingsService.smali:3051-3058`, кладёт в `itemIds` карту `"tv_input_hdmi_edid_version" → "g_fusion_picture__hdmi_edid_version"` с вызовом `Map#put`. В конструкторе этой службы строка присутствует в перечне настроек на строке 529. Это точное соответствие имён, а не ещё доказанный вызов `MtkTvConfig#setConfigValue` или иной HAL.
3. Read-only поиск точного литерала по распакованным smali дал: TvSettingsPlus 20 вхождений, Factory 1 (поле константы), KuSettings 0, MtkTvInput 0, TvServices 2. Отсутствие литерала в MtkTvInput не исключает вызова через Binder/конфигурационный ID или native слой.

**Открытая зависимость:** требуется проследить обработчик Settings.Global в `TVMenuSettingsService`, использование `itemIds`, конечный MediaTek API/HAL, семантику `g_fusion_picture__hdmi_edid_version` и привязку к двум физическим входам HW6/HW7. Не установлено, нужно ли hotplug для применения. Поэтому MOD C1 продолжает скрывать legacy single-port selector на 8054. Штатная OEM-страница остаётся доступной.

**Тест после разрешения владельца:** сначала только чтение ключа, HDMI source IDs и EDID readback отдельно на HW6/HW7 с сохранением исходного состояния. Любая запись EDID или переподключение HDMI требует отдельного разрешения и проверенного пути восстановления исходного значения. В текущем аудите записи и аппаратных тестов не было.
